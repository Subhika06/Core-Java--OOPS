# Core Java OOPS Assessment

## About
This repository contains 10 Java programs developed as part of the Core Java OOPS Assessment. These programs demonstrate the fundamental Object-Oriented Programming concepts using practical examples.

## Technologies Used
- Java
- Object-Oriented Programming (OOPS)

## Concepts Covered
- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Interfaces
- Method Overloading
- Method Overriding
- Runtime Polymorphism
