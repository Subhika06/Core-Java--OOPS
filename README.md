
# Employee Salary Processing

## Description
A Core Java application that calculates employee salaries based on employee type using Object-Oriented Programming concepts.

## OOPS Concepts Used
- Abstraction
- Encapsulation
- Inheritance
- Runtime Polymorphism
- Method Overriding

## Employee Types
1. Full-Time Employee
   - Salary = Monthly Salary

2. Contract Employee
   - Salary = Working Days × Daily Rate

## Technologies Used
- Java
- Scanner Class

## Sample Input
2
105 Arun
24 1500.0

## Sample Output
Employee ID: 105
Employee Name: Arun
Salary: 36000.00
